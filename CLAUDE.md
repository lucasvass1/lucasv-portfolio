@AGENTS.md

Quero padronizar as capas dos projetos do meu portfólio. Alguns projetos possuem screenshots da interface e continuarei utilizando essas imagens quando fizer sentido. No entanto, há projetos (principalmente APIs, backend, DevOps, infraestrutura e observabilidade) que não possuem uma interface visual para capturar.

Para esses casos, crie imagens de capa elegantes, modernas e profissionais, mantendo uma identidade visual consistente em todo o portfólio. As imagens devem transmitir o tema do projeto sem utilizar textos ou logotipos de empresas, priorizando elementos visuais relacionados à tecnologia.

Considere as seguintes diretrizes:

Estilo minimalista e premium, com aparência semelhante às capas de projetos do GitHub ou de portfólios de desenvolvedores experientes;
Fundo escuro seguindo a identidade visual do portfólio (tons próximos de #07090d);
Elementos abstratos relacionados à categoria do projeto, como código, servidores, APIs, microsserviços, containers, cloud, bancos de dados, observabilidade, dashboards, redes, automação, pipelines CI/CD e infraestrutura;
Efeitos sutis de iluminação, gradientes e formas geométricas para transmitir sofisticação, sem poluir o design;
Sem textos, sem nomes de tecnologias e sem logotipos;
Todas as imagens devem seguir o mesmo estilo visual para criar uma identidade consistente entre os projetos.

Além disso, defina um padrão visual para cada categoria de projeto, por exemplo:

Backend: servidores, APIs, bancos de dados, conexões e arquitetura distribuída;
DevOps: containers, pipelines CI/CD, cloud, automação e infraestrutura;
Frontend: interfaces modernas, componentes, layouts e elementos de UI/UX;
Full Stack: combinação de frontend e backend em uma composição equilibrada;
Cloud: nuvens, infraestrutura distribuída e serviços escaláveis;
Observabilidade: gráficos, métricas, logs, tracing e monitoramento;
Mobile: dispositivos móveis, telas de aplicativos e componentes nativos.

O objetivo é que todas as capas tenham um padrão visual elegante e profissional, valorizando o portfólio mesmo quando o projeto não possui uma interface para ser exibida.
