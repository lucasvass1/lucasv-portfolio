# Portfólio Profissional — Lucas Vasconcelos

Projeto de portfólio profissional desenvolvido com foco em design, performance, acessibilidade e manutenção.

## Stack base

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Framer Motion
- React Hook Form + Zod
- Lucide Icons

## Scripts

```bash
npm run dev
npm run lint
npm run build
npm run start
```
